## 확인 범위

본문, 코드, 사진 및 링크 미리보기 이미지의 눈으로 읽을 수 있는 정보와 OCR 결과를 확인했습니다. 사진의 계정명, 주소, 접속 정보, 명령 기록, 사용자 식별정보를 점검했습니다. 이 검사는 게시물의 공개 정보 검사이며 서버 취약점 검사나 침해 여부 확인은 아닙니다.

## 승인받아 가린 부분

- Wazuh 글의 테스트 계정 생성 명령에 포함된 비밀번호를 본문에서 `[비밀번호 가림]`으로 바꿨습니다.
- Wazuh 이미지 19, 20, 22, 23, 24, 25, 26, 27의 사용자·장치 식별정보, SID 등과 비밀번호를 불투명 검정 박스로 가렸습니다. 개인정보가 모인 로그 영역은 함께 가렸습니다.
- 새로 이전한 Wazuh 글의 가리기 전 이미지는 저장소에 넣지 않았습니다. HTML의 이미지 주소도 저장소의 공개용 사본을 가리킵니다.
- 그 밖의 문장은 원문과 대조하여 보존했습니다. BAS 글의 티스토리 전용 ‘더보기’ 기능은 같은 내용을 담은 HTML `details`로 옮겼습니다.

## 남아 있는 공개 정보

- 실습용 사설 IPv4 주소, 루프백 주소, OS 버전, 일부 실습 계정명은 남아 있습니다. 이들은 비밀번호가 아니며 사설 IP만으로 인터넷에서 직접 접속할 수는 없습니다.
- 기존 Atomic Red Team 글의 MAC 주소와 링크 로컬 IPv6 주소는 이전 검사에서 별도로 안내한 항목입니다. 해당 기존 사진은 이번 이전 과정에서 수정하지 않았습니다.
- 글의 작성자 표기와 블로그에서 공개 중인 프로필 정보는 유지했습니다.

## 원문에 필요한 후속 조치

티스토리 원문은 이번 작업으로 수정되지 않습니다. 원문에 남아 있는 동일한 사진·비밀번호도 별도로 수정해야 합니다. 노출된 테스트 계정이 아직 존재하면 삭제하거나 비밀번호를 바꾸고, 그 비밀번호를 다른 곳에서도 사용했다면 해당 비밀번호도 변경해야 합니다. 이미 공개된 비밀번호는 사진을 가린 것만으로 비밀로 되돌아가지 않습니다.
