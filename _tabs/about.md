## Parksejeong / PX

개발과 보안을 공부하며 남기는 개인 학습 노트입니다. 문제를 풀며 확인한 개념, 코드를 작성한 과정, 읽은 자료를 정리합니다.

## 기록의 범위

- **개발**: 코드와 구현 과정의 기록
- **CTF/Wargame**: 문제 풀이와 취약점 분석
- **Bug Bounty**: 웹 보안 학습과 리서치 노트
- **블로그/기술문서**: 블로그 운영과 기술 자료 정리
- **논문/컨퍼런스**: 읽은 논문과 발표 내용 정리
- **공모전/자격증**: 준비 과정과 활동 회고
