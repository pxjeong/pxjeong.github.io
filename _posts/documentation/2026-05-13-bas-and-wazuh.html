BAS란?

침해 및 공격 시뮬레이션(Breach and Attack Simulation)의 뜻으로 실제 환경에서 공격을 시뮬레이션을 함으로써 조직의 보안 상태를 사전 예방적으로 평가하는 역할을 합니다.

 

 

BAS(침해 및 공격 시뮬레이션)는 조직의 방어 체계 평가를 위해 다양한 사이버 공격을 시뮬레이션하는 과정을 자동화하는 사이버 보안 테스트 접근법입니다.

BAS의 장점은 기존의 취약점 평가 및 스캔이 단발성인 반면에 BAS는 지속적인 가시성을 제공함으로 보안 팀이 취약점이 발생하자마자 신속하게 대응이 가능합니다.

 

BAS가 왜 필요할까?

진화하는 다양한 공격들에 대비해 기업이 필요로 하는 평가 및 사전 보호의 핵심 요소입니다. BAS는 다양한 공격에 대비한 준비 태세를 보장하는 보안 취약점에 대한 지속적인 통찰력을 제공합니다.

또한 BAS는 다음과 같은 도움을 줍니다.

  • 잠재적 사이버 위험 완화: 발생 가능한 내부 또는 외부 위협을 조기에 경고해서 보안 팀이 심각한 데이터 유출, 접근 권한 상실, 이와 유사한 부작용이 있기 전에 문제 해결 활동의 우선 순위를 정할 수 있게 합니다.
  • 사이버 공격 성공 가능성 최소화: 끊임없이 변화하는 위협 환경에서 자동화를 하면 지속적인 테스트를 통해 복원력을 높일 수 있습니다.

 

 

BAS 도구가 시뮬레이션할 수 있는 주요 공격 유형은 다음과 같습니다.

공격 유형 시뮬레이션 내용 점검 목적
랜섬웨어 배포 랜섬웨어 감염 상황을 재현하여 탐지·격리·복구 과정 테스트 직원 보안 인식 수준 확인 및 이메일 보안 취약점 파악
측면 이동 전술 공격자가 내부 네트워크에서 다른 시스템으로 확산되는 과정 모방 랜섬웨어 대응 능력 및 백업 안전성 점검
데이터 유출 기법 민감한 데이터를 외부로 빼내는 공격 상황 시뮬레이션 네트워크 분리 및 내부 보안 통제 효과 확인
피싱 공격 가짜 이메일·사이트 등을 이용해 직원이 피싱을 식별하는지 테스트 DLP(Data Loss Prevention) 및 암호화 보호 수준 점검
중간자 공격 통신 중 데이터를 가로채거나 변조하는 공격 재현 암호화 및 안전한 통신 프로토콜 적용 여부 확인
SQL 인젝션 시도 웹 애플리케이션에 악성 SQL 구문 삽입 시도 웹·DB 보안 취약점 및 입력 검증 문제 탐지

 

BAS 시뮬레이션은 어떤 과정으로 돌아갈까?

 

1단계 - 공격 대상 지정

더보기

예시:

  • Ubuntu 서버
  • Windows PC
  • 웹 서버
  • 사내 PC

2단계 - 공격 시나리오 선택

더보기

예시:

  • 피싱 메일 공격
  • brute force 공격
  • 랜섬웨어 동작
  • 권한 상승 공격
  • 파일 탈취 공격

3단계 - 공격 실행

더보기

그 다음 BAS가 자동으로 공격 행동을 수행한다.

예를 들어 brute force 공격이면 비밀번호를 자동 시도를 한다.

그러면 대상 서버에서는

  • 로그인 실패 로그 발생
  • SSH 이벤트 발생
  • auth.log 기록 생성

4단계 - 보안 대응 분석

더보기

시뮬레이션 환경에서 실행되는 BAS 도구는 탐지 속도, 방어 메커니즘의 견고성, 공격 경로로 활용될 수 있는 취약점 등 보안 통제가 이러한 사건에 어떻게 반응하는지 기록합니다. 시뮬레이션 중 대응을 모니터링함으로써 실시간 대비 태세를 확보하기 위해 개선이 필요한 영역을 식별할 수 있습니다.

5단계 - 개선

더보기

마지막 단계에서는 보안 개선을 위해 생성된 보고서의 적용을 보여줍니다. 조직은 해당 결과를 바탕으로 방어 체계를 수정하고, 변경 사항의 효과를 측정하기 위해 새로운 시뮬레이션을 실행합니다. 결과적으로 이 프로세스는 반복적이고 적응적인 시뮬레이션 결과를 기반으로 보안의 지속적인 향상을 규정합니다.

 

대표적인 BAS의 도구로는 다음이 있다.

Atomic Red Team

MITRE ATT&CK 기반의 작은 단위 공격 시뮬레이션 도구이다.
각 테스트(Atomic Test)는 특정 ATT&CK 공격 기법 1개를 재현하며, 보안 솔루션이 이를 탐지하는지 확인하는 데 사용된다.

특징

  • ATT&CK 기법별 테스트 제공
  • 설치와 사용이 간단함
  • EDR/SIEM 탐지 검증 가능
  • 오픈소스 기반 무료 사용 가능

공격 흐름

  • PowerShell 실행
  • 자격 증명 덤프
  • 악성 파일 실행

 

MITRE CALDERA

MITRE ATT&CK 기반의 자동화 레드팀 시뮬레이션 플랫폼이다.
실제 공격자처럼 여러 공격 단계를 연결하여 전체 공격 흐름을 자동으로 수행할 수 있다.

특징

  • 공격 체인 자동화 가능
  • 실제 해커 행동 흐름 재현
  • 레드팀·블루팀 훈련 활용
  • 반복적인 보안 검증 가능

공격 흐름

피싱 → 권한 상승 → 내부 이동 → 데이터 탈취

 

 

Wazuh란?

Wazuh는 오픈소스 기반의 SIEM(Security Information and Event Management) 및 XDR 플랫폼이다.
서버, PC, 네트워크 장비 등에서 발생하는 로그와 이벤트를 수집·분석하여 침입 시도나 이상 행위를 탐지하고 대응하는 역할을 한다.

Wazuh는 실시간 보안 모니터링 기능을 제공하며, 다양한 공격 행위를 탐지하고 관리자에게 경고(Alert)를 전달할 수 있다. 또한 보안 이벤트를 중앙에서 통합 관리할 수 있어 기업이나 기관의 보안 관제 시스템(SOC)에서 많이 사용된다.

Wazuh가 왜 필요할까?

최근 사이버 공격은 단순 악성코드뿐만이 아닌

  • brute force 공격
  • 권한 상승
  • 내부 침투
  • 랜섬웨어
  • 데이터 탈취

등 다양한 형태로 발전하고 있다. Wazuh는 이러한 공격 흔적을 실시간으로 분석하여 보안 관리자가 빠르게 대응할 수 있도록 도와준다. 또한 다음과 같은 장점이 있다.

  • 실시간 위협 탐지 가능
  • 중앙 집중형 로그 관리 가능
  • 취약점 및 파일 변경 감시 가능
  • 오픈소스 기반으로 무료 사용 가능
  • 다양한 운영체제와 연동 가능

Wazuh의 주요 기능

로그 분석 시스템 및 보안 로그를 수집·분석
침입 탐지 비정상 행위 및 공격 시도 탐지
파일 무결성 검사(FIM) 중요한 파일 변경 여부 감시
취약점 탐지 시스템의 보안 취약점 확인
Active Response 특정 공격 발생 시 자동 대응 수행
SIEM 기능 보안 이벤트 중앙 관리 및 시각화

Wazuh가 탐지할 수 있는 공격 유형

brute force 공격 반복 로그인 실패 탐지 계정 탈취 시도 확인
권한 상승 공격 sudo 사용 및 관리자 권한 획득 감시 내부 공격 탐지
랜섬웨어 파일 대량 변경 및 암호화 행위 탐지 랜섬웨어 조기 대응
악성 파일 실행 의심 프로세스 및 악성코드 실행 감지 시스템 감염 방지
비정상 로그인 해외 IP·비정상 시간 로그인 탐지 계정 보안 강화
파일 변조 주요 시스템 파일 변경 감시 시스템 무결성 보호

  • 웹 서버

더보기

3단계 - 분석 및 탐지

수집된 로그를 분석하여 공격 패턴이나 이상 행위를 탐지한다.

더보기

  • 악성 명령 실행

더보기

설정에 따라 자동 대응을 수행할 수 있다.

더보기

예시

  • 사용자 계정 잠금
  • 프로세스 종료

Wazuh와 BAS의 관계

BAS가 공격을 시뮬레이션하면 Wazuh는 그 공격을 탐지하고 대응하는 역할을 수행할 수 있다.
즉 BAS는 실제 해커의 행동을 재현하고, Wazuh는 시스템에서 발생하는 로그와 이벤트를 분석하여 위협 여부를 판단한다.

BAS가 brute force 공격이나 권한 상승 공격을 실행하면 시스템에서는 로그인 실패 기록, SSH 접속 로그, 관리자 권한 사용 기록 등의 이벤트가 생성된다. 이후 Wazuh가 이를 실시간으로 분석하여 이상 행위를 탐지하고 관리자에게 경고(Alert)를 발생시킨다. 또한 설정에 따라 공격 IP 차단이나 계정 잠금 같은 자동 대응 기능도 수행할 수 있다.

결론은 BAS와 Wazuh를 함께 사용하면 단순 공격 테스트뿐만 아니라 공격 탐지 및 대응 과정까지 전체적으로 검증할 수 있다.

결론

  • BAS = 공격 시뮬레이션
  • Wazuh = 공격 탐지 및 대응

역할이라고 볼 수 있다.
